## Мета роботи

Навчитися підвищувати надійність викликів інструментів агентом за допомогою перевірок синтаксису, схеми та змісту аргументів. Реалізувати перевірки з використанням бібліотеки Pydantic, додати обробку помилок та обмеження кількості невдалих викликів. Підключити трасування Langfuse для спостереження за роботою агента та порівняти результати до і після впровадження перевірок.

## 1. Вихідні дані та підготовка проєкту

Для виконання лабораторної роботи використано агента, розробленого в лабораторній роботі №2 за варіантом 7 «Подорожі».

Агент відповідає на запитання про подорожі, підбирає маршрути вихідного дня та розраховує бюджет поїздки. Для цього використовуються три основні інструменти та один заборонений для перевірки обмежень:

- `search_routes` – пошук маршрутів вихідного дня за категоріями;

- `transport_info` – отримання інформації про транспорт із довідника;

- `calc_budget` – розрахунок загального бюджету поїздки з урахуванням кількості людей та додаткових витрат;

- `buy_ticket ` — заборонена дія (купівля квитків), яка блокується диспетчером для перевірки безпеки та прав доступу.

У роботі використано локальну модель qwen2.5:3b через Ollama. У фінальному прогоні використано такі значення параметрів моделі:

- `MAX_STEPS = 6`

- `TEMPERATURE = 0.2`

Для перевірки роботи агента використано ті самі п'ять завдань: Z1, Z2, Z3, P1 та P2. Під час доопрацювання було змінено описи функцій у schemas.py, правила валідації та повідомлення у checks.py ; тому порівняння описує фактичні версії, а не ізольований вплив однієї зміни.

Створено окремий каталог lab3, до якого скопійовано програмні файли та корпус даних із попередньої лабораторної роботи (data/corpus/transport.csv). Також створено нове віртуальне середовище Python 3.12.10 та встановлено необхідні бібліотеки: openai, pydantic, python-dotenv і langfuse.

## Класи аргументів (`arguments.py`)

```python
"""Класи аргументів інструментів."""
from typing import Literal
from pydantic import BaseModel, ConfigDict, Field


class SearchRoutesArgs(BaseModel):
    model_config = ConfigDict(extra="forbid")
    query: str = Field(description="Пошуковий запит для маршруту українською")


class TransportInfoArgs(BaseModel):
    model_config = ConfigDict(extra="forbid")
    route: str = Field(description="Назва маршруту")


class CalcBudgetArgs(BaseModel):
    model_config = ConfigDict(extra="forbid")
    price_per_person: float = Field(gt=0, description="Ціна квитка на одну особу в один бік")
    people: float = Field(gt=0, description="Кількість людей")
    extra: float = Field(ge=0, description="Додаткові витрати")


ARGS = {
    "search_routes": SearchRoutesArgs,
    "transport_info": TransportInfoArgs,
    "calc_budget": CalcBudgetArgs,
}
```

## Перевірка ланцюжка перевірок

Файл `test_checks.py` викликає `call_tool` без моделі з навмисно зламаними викликами. Результат прогону:

Таблиця 2 — Перевірка ланцюжка перевірок

| Що перевіряємо | Виклик | Рівень | Повідомлення для моделі |
| --- | --- | --- | --- |
| **Зламаний JSON** | `calc_budget({"price_per_person": 750, "people": 2, "extra": 500` *(обірваний рядок)* | `syntax` | Помилка: аргументи не пройшли перевірку. Поле JSON: Invalid JSON: EOF while parsing an object at line 1 column 49. Виправ аргументи і виклич інструмент ще раз. |
| **Неправильний тип** | `calc_budget({"price_per_person": "сімсот", "people": 2, "extra": 500})` | `schema` | Помилка: аргументи не пройшли перевірку. Поле price_per_person: Input should be a valid number, unable to parse string as a number. Виправ аргументи і виклич інструмент ще раз. |
| **Відсутнє обов'язкове поле** | `calc_budget({"people": 2, "extra": 500})` | `schema` | Помилка: аргументи не пройшли перевірку. Поле price_per_person: Field required. Виправ аргументи і виклич інструмент ще раз. |
| **Вигадане поле** | `calc_budget({"price_per_person": 750, "people": 2, "extra": 500, "unknown": 123})` | `schema` | Помилка: аргументи не пройшли перевірку. Поле unknown: Extra inputs are not permitted. Виправ аргументи і виклич інструмент ще раз. |
| **Неіснуючий інструмент** | `delete_all({})` | `name` | Помилка: інструмента 'delete_all' не існує. Доступні: search_routes, transport_info, calc_budget. Виклич один з доступних або повідом користувачу, що такої дії немає. |
| **Заборонена дія** | `buy_ticket({})` | `permission` | Помилка: інструмент 'buy_ticket' недоступний. Не повторюй виклик, повідом користувачу, що ця дія недоступна. |
| **Значення немає в довіднику** | `transport_info({"route": "Неіснуючий маршрут 999"})` | `meaning` | Помилка: маршруту 'Неіснуючий маршрут 999' немає в довіднику. Точну назву маршруту можна дізнатися за допомогою пошуку. Виправ назву маршруту або повідом користувачу, що даних про цей маршрут немає. |
| **Значення поза межами** | `calc_budget({"price_per_person": -100, "people": 2, "extra": 500})` | `schema` | Помилка: аргументи не пройшли перевірку. Поле price_per_person: Input should be greater than 0. Виправ аргументи і виклич інструмент ще раз. |
